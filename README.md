# AI Content Helper 🚀

Современная SaaS-платформа для автоматической генерации вовлекающего контента с помощью искусственного интеллекта. Сервис позволяет в один клик создавать адаптированные публикации для **Telegram**, экспертные статьи для **VC.ru** и ультра-короткие емкие мысли для **X (Twitter)**, учитывая выбранную тональность текста.

---

## 🛠 Технологический стек

Проект разработан на базе надежного и масштабируемого архитектурного каркаса:

- **Frontend:** React 19 (Vite), Tailwind CSS 4, Lucide React (иконки).
- **Backend:** Django 6.1, Django REST Framework (DRF), JWT Authentication (Simple JWT + `dj-rest-auth`).
- **Асинхронные задачи:** Celery 5.6, Redis 7 (в качестве брокера и бэкенда результатов).
- **База данных:** PostgreSQL 15.
- **Контейнеризация:** Docker, Docker Compose.
- **Интеграции:** OpenAI API (модель `gpt-4o-mini`), Google OAuth 2.0.

---

## 🏗 Архитектура проекта

Проект разбит на два независимых слоя, объединенных в общую Docker-сеть:

1.  **Бэкенд-инфраструктура:** Django-приложение обрабатывает API-запросы, управляет лимитами тарифов и пользователями. Тяжелые запросы к нейросети выносятся в фоновые воркеры Celery через Redis, исключая зависание веб-сервера для клиента.
2.  **Фронтенд-студия:** Быстрое SPA-приложение на React взаимодействует с бэкендом через кастомный слой `axios` с автоматическим перехватом и подстановкой JWT-токенов.

## 🚀 Быстрый запуск (Развертывание в 1 клик)

Процесс инициализации базы данных, генерации миграций, настройки **Google OAuth** и наполнения тарифной сетки полностью автоматизирован.

### Требования к системе

На вашем компьютере должны быть установлены:

- [Docker](https://docker.com)
- Docker Compose

### Инструкция по установке

1.  **Клонируйте репозиторий с проектом:**

    ```bash
    git clone <https://github.com/Na1x-dev/ai_content_helper.git>
    cd ai-content-helper
    ```

2.  **Настройте переменные окружения:**
    Скопируйте шаблон конфигурации в рабочий файл `.env`:

    ```bash
    cp .env.example .env
    ```

    Откройте созданный файл `.env` и укажите ваш API-ключ OpenAI и учетные данные Google приложения (подробнее в разделе [Конфигурация](#конфигурация)).

3.  **Запустите автоматический скрипт развертывания:**
    - **На Linux / macOS:**
      ```bash
      chmod +x run.sh
      ./run.sh
      ```
    - **На Windows (в PowerShell/CMD):**
      ```bash
      docker compose up --build
      ```

Скрипт сам дождется готовности PostgreSQL, создаст таблицы, накатит тарифные планы, настроит интеграции и запустит проект.

### Ссылки для доступа к сервисам:

- **Фронтенд (Интерфейс студии):** [http://localhost:5173](http://localhost:5173)
- **Бэкенд (Django API):** [http://localhost:8000/api/](http://localhost:8000/api/)
- **Панель администратора Django:** [http://localhost:8000/admin/](http://localhost:8000/admin/)

## ⚙️ Конфигурация (.env)

Основные переменные, необходимые для стабильной работы платформы:

```ini
DEBUG=True
AI_MOCK_MODE=True                 # Переключите в False для отправки реальных запросов в OpenAI
OPENAI_API_KEY=YOUR_KEY_HERE     # Токен доступа OpenAI
OPENAI_BASE_URL=https://proxyapi.ru # Прокси-урл для работы без VPN в СНГ

# Настройки базы данных для Docker
POSTGRES_DB=YOUR_DB
POSTGRES_USER=YOUR_DB_USER
POSTGRES_PASSWORD=YOUR_PASSWORD
DATABASE_URL=postgres://YOUR_DB_USER:YOUR_PASSWORD@db:5432/YOUR_DB

# Интеграция Google Auth (Префикс VITE_ критичен для фронтенда)
VITE_GOOGLE_CLIENT_ID=YOUR_CLIENT_ID://googleusercontent.com
GOOGLE_CLIENT_SECRET=YOUR_CLIENT_SECRET

# Данные для автоматического создания администратора сайта
ADMIN_USER=admin
ADMIN_EMAIL=admin@example.com
ADMIN_PASSWORD=secure_password_123
```

## 💳 Тарифные планы и Лимиты

Система динамически управляет суточными лимитами генераций. Сброс счетчика происходит автоматически раз в сутки при первом запросе пользователя.

При старте контейнера скрипт `init_saas` создает в базе данных следующие планы:

- **Базовый доступ (free):** 3 публикации в сутки, стандартная скорость.
- **Стандартный (standard):** 25 публикаций в сутки, повышенная скорость.
- **Продвинутый (pro):** 50 публикаций в сутки, аналитика стилей, метка «Популярно».
- **Максимальный (max):** 100 публикаций в сутки, выделенный сервер генераций.

## 🛠 Полезные команды для разработки

Если вам необходимо вручную управлять контейнерами или изолированно работать с компонентами:

- **Полная очистка данных и сброс томов БД (Hard Reset):**
  ```bash
  docker compose down -v
  ```
- **Просмотр логов бэкенда в реальном времени:**
  ```bash
  docker compose logs -f web
  ```
- **Просмотр работы воркеров Celery:**
  ```bash
  docker compose logs -f celery_worker
  ```
- **Ручное создание новой миграции базы данных:**
  ```bash
  docker compose exec web python manage.py makemigrations
  ```
